# 实现计划

## 方案

先从路由、动态菜单、初始化命令和构建配置反查引用，再按“业务必需、工程必需、演示残留、生成物”分类。
业务页面继续保留；未进入初始化菜单且无静态引用的上游演示页面、mock 方案和过期文档删除。新增结构文档和
标准库单元测试固定保留边界。

## 影响面

- 后端：不修改应用代码、模型、接口或迁移。
- 前端：删除演示视图、示例图标、表格 mock API 和未加载的 mock 目录；保留业务页面和动态加载入口。
- 数据与迁移：无变化。
- 部署与配置：删除旧 Travis 配置；保留 GitHub Actions、Docker、Nginx 和开发容器配置。

## 验证策略

- 使用静态测试校验必需业务路径存在、清理目标不存在、动态路由兼容映射存在。
- 校验 `package.json` 与锁文件不再声明仅 mock 使用的依赖。
- 运行 `python ai/quality/quality.py quick`，确认文档、规格、语法和工具测试通过。
- 重新生成驾驶舱，确认新规格与验证结果可见。

## 回滚方案

本次删除项均为无引用的模板资源。需要恢复时，可从上游 `vue-admin-template` 或版本历史取回对应文件；
业务数据、迁移和接口不受影响。
