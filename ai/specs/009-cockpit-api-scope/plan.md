# 实现计划

新增共享的 `CORE_API_GROUPS` 元数据，包含模块、方法、路径和说明。驾驶舱生成器使用该数据
渲染可展开清单；核心测试运行器在响应中附带同一份数据。点击测试按钮时，前端脚本自动展开清单，
测试完成后继续保留清单和测试结果。

页面使用现有原生 `<details>` 和 CSS，不增加脚本依赖。API 清单来自固定测试契约元数据，并与
后端 91 项测试覆盖的接口一致。

## 影响面

- 后端业务：无。
- 前端业务：无。
- 驾驶舱：新增 API 范围展示。
- 测试工具：测试运行器增加响应元数据。

## 验证策略

- 先生成器测试验证 API 清单、分组和 38 个方法/路径组合。
- 运行器测试验证响应携带同一元数据。
- 更新驾驶舱并用 Chrome 检查点击后清单自动展开。
- 运行 quick 和核心测试。

## 回滚方案

删除共享元数据和页面清单模板即可回退；测试执行逻辑不受影响。
