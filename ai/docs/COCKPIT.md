# 开发驾驶舱

驾驶舱是仓库状态的本地视图，来源包括规格 Markdown、源码目录和最近一次验证报告。它不连接
生产数据库，也不会读取 `business/.env` 中的密钥。页面本身仍是单文件静态产物；通过本地
`serve` 打开时会额外启用“一键测试核心功能”。

生成并打开：

```bash
python ai/quality/quality.py cockpit
python ai/quality/quality.py serve --port 8765
```

然后访问 `http://127.0.0.1:8765/`。生成文件是 `ai/cockpit/index.html`，可以直接提交或归档。

页面展示：

- 最近一次验证的档位、总状态、耗时和每个门禁结果；
- 活动规格的目标、状态、验收项完成度和任务完成度；
- 后端应用、测试数量、前端页面和测试数量；
- 后端与前端覆盖率；
- 一键运行核心后端 API 与前端单元测试，并展示用例数、耗时和失败输出；
- 常用验证命令和关键工程文档入口。

页面顶部的“验证通过 / 部分验证 / 验证失败 / 未验证”来自最近一次真实门禁报告。失败门禁可以
展开查看原始输出；规格进度直接读取 `spec.md` 与 `tasks.md` 的复选框。驾驶舱不会把没有报告的
项目显示成通过。

“一键测试核心功能”调用仅监听本机服务的 `POST /api/core-tests/run`。直接打开
`ai/cockpit/index.html` 时按钮会禁用，避免在 file 模式误以为测试已经执行。该接口拒绝远程客户端
和缺少专用请求头的请求，并使用内存 SQLite、locmem cache 运行测试。

驾驶舱和 `ai/reports/report.json` 都是生成物。要改变展示结果，应重新运行验证或修正规格/策略。
仅想刷新静态页面而不运行质量门禁时，使用 `cockpit` 子命令；此时页面会明确标注“未验证”。
